# `solidity-perf` — gas snapshot harness

This directory pins a `forge snapshot` baseline for the Solidity backend so
that every PR touching `serde-generate/src/solidity.rs` shows up as a diff
in `.gas-snapshot`.

## Files

- **`Library.sol`** — checked-in output of the codegen for a canonical
  registry of types (primitive ints, `bytes`, `string`, `Vec<T>`,
  `Option<T>`, fixed-size arrays, simple/complex enums, nested structs).
  Regenerated by the workspace-level example
  `cargo run --features solidity --example generate_perf_library`.
- **`Harness.sol`** — hand-written wrapper exposing one external
  `ser_*` / `deser_*` entry point per measured shape. Imports
  `Library.sol`.
- **`test/Bench.t.sol`** — one `test_*` function per measurement, each
  calling a single Harness entry point with deterministic input.
- **`.gas-snapshot`** — output of `forge snapshot`. Committed.
- **`foundry.toml`** — pinned `solc_version`, `via_ir`, `optimizer_runs`,
  `evm_version` so the snapshot is reproducible.

## Update flow

After any change to `serde-generate/src/solidity.rs`:

```bash
# 1. regenerate the canonical library from the new codegen
cargo run --features solidity --example generate_perf_library

# 2. refresh the foundry snapshot
( cd serde-generate/solidity-perf && forge snapshot )

# 3. commit both
git add serde-generate/solidity-perf/Library.sol \
        serde-generate/solidity-perf/.gas-snapshot
```

The CI `test-solidity` job re-runs steps 1 and 2 in `--check` mode and
fails if either file is stale, so any codegen change shows up as a
visible `Library.sol` and `.gas-snapshot` diff in PR review.

## When to add a benchmark

Add a new `test_<name>` to `test/Bench.t.sol` (with a matching Harness
entry point) when:

- the codegen grows a new shape that isn't already covered by one of
  the existing entry points, or
- you want to track a specific input size (e.g. a large `bytes` payload
  representative of a production message).

Keep benchmarks deterministic — no time, no randomness, no storage.
`view`/`pure` functions only.
